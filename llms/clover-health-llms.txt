# Clover Health

> Clover Health is a Medicare Advantage health insurer whose public developer program exposes a FHIR R4 Formulary and Provider Directory API, plus a consent-based Patient Access API. The APIs implement the CMS Interoperability and Patient Access rule (CMS-9115-F); Clover was the first payer live on a CMS-aligned/TEFCA network. This file is generated by the API Evangelist enrichment pipeline from the provider's public developer surface.

## APIs

- [Formulary & Provider Directory API (Swagger)](https://public-api.cloverhealth.com/swagger): FHIR R4 read API — covered drugs, plans, providers, locations, and organizations. Base host https://public-api.cloverhealth.com
- [Patient Access API (docs)](https://fhir.docs.careevolution.com/interface/r4/): Member health and claims data in FHIR R4, released after member consent, delivered via CareEvolution.
